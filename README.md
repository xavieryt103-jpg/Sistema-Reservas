# Sistema de Reservas

Sistema para gestionar clientes, servicios y reservas de una empresa de servicios.

## Requisitos
- Node.js 18 o superior

## Uso
npm start

## Pruebas
npm test

## Modulos
- Clientes: permite registrar clientes, modificar su informacion y consultarlos.
